# akhsa505

Portfolio pribadi M. Akhsya Hidayat — HTML, CSS & JavaScript murni, di-hosting di Netlify.

- `index.html` — struktur halaman (Hero, About, Skills, Work, Contact)
- `style.css` — tema, layout, animasi
- `script.js` — loader, kursor, kanvas jaringan, scroll reveal, validasi & pengiriman form
- `images/profile.jpg` — foto profil

Form kontak menggunakan Netlify Forms; pesan masuk bisa dilihat di dashboard Netlify → Forms.
